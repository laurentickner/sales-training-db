# Batch 1 — Mining Findings

> Source: 14 Cole Gordon YouTube transcripts. `>>` = speaker change, `[ __ ]` = censored profanity (left as-is).
> Cole's core objection model: 3 buckets — **uncertainty** (top of pyramid, must clear first), **support** (spouse/partner/board/team), **financial** (true logistics, not "not worth it"). The universal first move on ANY objection is a diffuser ("no problem") + an isolation tie-down to test if the prospect is truly sold.
